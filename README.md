# Tapo D210 to Matter Bridge (Middleware)
Ce projet expose les événements de la sonnette D210 à Matter via Matterbridge.

## Déploiement (Flint 2 / Linux)
1. Extraire : `tar -xzvf tapo_matter_bridge.tar.gz`
2. Installer : `npm install`
3. Configurer : Modifier `.env` avec vos accès.
4. Lancer : `npm start` ou utiliser `pm2`.
